4. HOW TO READ THIS
-------------------------------------------------------------------------------------
- Each rule set looks good only on the data it was chosen on:
    R3: Calmar 9.42 on 2025-26 (fitted)    -> 0.07 on 2023-25 (not fitted)
    R4: Calmar 5.53 on 2023-25 (fitted)    -> -0.02 on 2025-26 (not fitted)
  That pattern means the large in-sample numbers are mostly fitting. Only Semi-Directional's
  expiry-day credit spread made money in both directions of the test.
- The 2025-26 test year (T7/T10) is not perfectly clean: R3 had been fitted on it earlier.
- Stale labels: the report.md files in 23-26/, 23-25_dhan/ and test_2025_26/ were generated before
  the labelling fix and all say "IN-SAMPLE". Use this register (and each folder's README.md) instead:
  23-25_dhan/ and test_2025_26/ are out-of-sample tests, 23-26/ is mixed.
- Before/after files (*_before_after.*) inside a folder compare the folder's rules with the previous
  version on the SAME data. In results/ they compare R3 (before) with R4 (after).
- Duplicates: test_2025_26/ = results/;  Analysis/3_Code_and_Data/results* = results/ + results/development/.
